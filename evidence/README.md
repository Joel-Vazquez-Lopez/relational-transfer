# Research evidence foundation (2026-10-15)

This directory is a **curated index**, not a complete import of the 4,447-file research package. It is intended as a common, checkable baseline for independent investigators.

**Source package:** `COMPASS_RESEARCH_FOUNDATION_2026-10-15.zip`, stored outside Git in the researcher's ChatGPT Library/local archive. SHA-256: `4d005bffa43131a0f24d4e52a33c076617578489181b8b4db4b19276362793ae`. The verified archive contains 4,447 files plus a directory entry, with source code, protocols, experiment records, raw predictions, and package hashes. The included `VERIFY_PACKAGE.py` verifies entries and recomputes selected metrics. The GitHub copy does **not** include its large raw datasets.

Reading order:
1. `EXPERIMENT_REGISTRY.md` for measured results and caveats.
2. `SOURCE_PROVENANCE.md` for exact original paths, checksums, and scope.
3. `REPRODUCTION.md` for the raw-data validation workflow.
4. `OPEN_QUESTIONS.md` for hypotheses explicitly separated from established findings.
5. `../research/WORKSTREAMS.md` for collaboration rules.

**Status key:** ARCHIVAL-REPORTED = backed by archived records but not independently reproduced in this branch; AUDITED-DERIVED = checked using included archive documentation and source existence; EXPLORATORY = repeatedly used or non-independent evaluation; UNVERIFIED = needs raw reanalysis / independent replication. Do not convert archival summaries into confirmed mechanistic conclusions.

Do not store model weights, API credentials, `.env` files, restricted corpora, unpublished sealed evaluations, or reviewer-only datasets here. Historical frozen results are immutable. New research enters via scoped branches and review.
