# Learned clause selection followed by frozen operation choice

## Design

This exploratory follow-up tests the gap exposed by [v4](../goal_first_decomposition_v4_2026-10-13/RESULTS.md): the clause-trained model could choose operations from supplied normalized views but usually failed on an intact mixed question. A separate Transformer token classifier learned which question words to retain for each step, using explicit keep/drop labels on 6,000 FF/RR training questions. Its predicted masks were applied to new intact questions and passed to each seed's **frozen** v4 operation model. No gold clause boundary was supplied at test time. The [protocol](PROTOCOL.json) was frozen before these runs; the [audit](analyze.py) checks the saved records and [summary](ANALYSIS.json).

The new test bank contains 400 FF/RR and 400 FR/RF examples. No complete sentence/question pair appeared in any previous bank. The mixed *operation pairs* and exact mixed question strings were absent from selector and planner **training**. However, 287/400 mixed items reuse a question string from the earlier v4 mixed **evaluation** with different facts. The remaining 113/400 have question strings not present in that earlier evaluation; they form a useful narrower check, not an independent test of new grammar. Five selector starts were paired with the five corresponding v4 planner starts.

## Result

On each of five starts, the learned selector produced **both** exact clause masks on 400/400 mixed questions. With its predicted masks, the frozen operation model chose **both** correct directions on 400/400. Oracle masks gave the same 400/400. The same frozen planner applied directly to intact mixed questions scored 0, 0, 12, 0, and 0 out of 400 across the five starts. On the **113 question strings not seen in v4 evaluation**, selection and both operation choices were 113/113 for all five starts; the intact-question planner scored 0, 0, 5, 0, and 0. All systems scored 400/400 on the new in-domain questions. The prespecified exploratory gate passed in all five starts.

These counts concern two direction labels, **not final event answers**. The model sees a restricted generated grammar with highly regular clause markers. A hand-written clause-boundary rule yields the same oracle-view result. The selector receives explicit decomposition targets and adds a separate model, so this is not a compute-matched improvement over a single full-question model. It did not discover a general algorithm from answer-only training. We have shown that, in this small setting, a learned route from intact question to local operation views can preserve the useful clause-level transfer from v4. The next test must vary grammar and operation dependencies, then include complete answer execution and natural sentences. Until then this is a feasibility result for the proposed architecture, not a conference-level method claim.
