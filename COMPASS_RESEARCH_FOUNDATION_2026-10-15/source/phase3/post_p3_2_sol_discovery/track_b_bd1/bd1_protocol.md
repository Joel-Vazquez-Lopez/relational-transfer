# B-D1 frozen discovery protocol — candidate-state action transport

**Status:** Discovery-only prospective-within-discovery test. Freeze this file, the three B-D1 scripts, and the raw scene-plan hash before any B-D1 model forward. P3.2-E remains the canonical endpoint. The old P3.2 VY *aggregate score* was seen in B00; it is prior exploratory knowledge, not a B-D1 selection input or untouched confirmation. No old P3.2 composed row or state is used here. All B-D1 scenes are newly generated, with composition inputs fixed before the first forward.

## Boundary and design

- Models: A/B/C/D × seeds 1701 and 1703 (8 existing permitted discovery checkpoints), with exact hashes verified against `phase3/p3_0_r/checkpoint_policy.json`. No retraining. Seeds 1704–1706 and all protected/confirmatory material are excluded.
- Inputs: deterministic fresh `pilot.scene` instances with six identities and two events. Per one of 48 non-held directed meanings: 6 fit, 2 single-action validation, 2 held-out scene-test instances. Per one of 12 held-pair directed meanings: 8 held-out identity-test instances. Total 576 BASE scenes/model, of which 288 fit, 96 validation, 192 test. The same raw scenes are paired across models. The distractor is deliberately selected from the three spare identities other than the highest spare so Y changes one identity. Every instance has an oracle query of its scene meaning. Fit/validation/test have disjoint geometry; test contains a separately marked withheld relational-pair stratum.
- Actions: V rotates all object xy coordinates by +90° via `(x,y) -> (-y,x)`; Y replaces only the distractor identity one-hot with the highest identity outside the relation endpoints. Y leaves geometry fixed. They commute as raw-input edits. `V²`, `VY`, `V²Y`, and `V⁴` are constructed from the fixed BASE input; `V⁴` is an input closure/identity sanity check, not positive evidence of an internal operator. No `V³` forward is needed.
- Raw scene plan includes all action inputs and hashes, but **only BASE/V/Y are forwarded before the fit/prediction freeze**. The held-out composed inputs and any outcome path must never be read by the prepare/fit process. An acquisition script is separately invoked only after `bd1_fit_freeze.json` verifies the plan, source scripts, models, fit parameters and sealed predictions.

## State, maps, fitting and information budgets

- **Primary state:** candidate encoder post-block-1 CLS vector, 48 dimensions, before final LayerNorm. Full post-block-1 4×48 token tensor is a *predefined alternative*, not a rescue selected after outcomes. Both are measured for BASE/V/Y on fit scenes. The primary map is applied to the CLS only; the three non-CLS tokens remain BASE tokens for patching. Because only LayerNorm follows this stage, a successful patch shows downstream functional sufficiency at the readout boundary, **not** a deeper causal circuit.
- For each checkpoint and action a∈{V,Y}, fit fixed rank-8 residual affine ridge `T_a(h)=h+mean(Δ_a)+(h−mean(h)) B_a`, where `B_a` is the rank-8 SVD truncation of the ridge solution for centered `Δ_a=h(a)−h(BASE)`. Ridge α=1 on unstandardized states. No tuning. This has at most 816 free scalar coefficients/action (plus fitted input center), versus 48-dimensional additive delta. Fit only the 288 scene-disjoint non-held meanings. Fit the full-token alternative by exactly the same rank-8 rule on 192 dimensions (higher information/capacity, reported separately and ineligible to rescue the primary gate).
- Map inputs contain the current candidate state and fixed action identity through choosing the V/Y map. They receive no scene ID, query label, composed outcome, or action-history tag. Apply them recursively without refitting or correction: `T_V²`, `T_Y T_V`, `T_V T_Y`, `T_Y T_V²`, `T_V² T_Y`, `T_V⁴`.
- A fixed generic nonlinear comparator is a separate 48→8→48 ReLU residual MLP/action (824 parameters), Adam lr 0.003, 200 full-batch epochs, seed 881+action index, MSE plus weight decay 0.001; fit from the same 288 BASE→single pairs. An additive-delta baseline uses mean `h(a)-h(BASE)`. A nearest-neighbor baseline uses Euclidean nearest training BASE state and adds its observed single-action delta at each recursive step. Identity applies no change.
- A privileged raw-geometry/task-semantic comparator receives the flattened current 3×14 input plus one-hot source, target and event; it fits a full affine ridge (56 inputs × 48 outputs plus intercept; 2,736 coefficients) from the BASE/V/Y scene input to the corresponding 48-dimensional state using fit singles only, then predicts the state of the *raw composed scene*. It has more input information and capacity than T and is a strong explanatory null. It may not use a composed network outcome.
- Validation BASE/V/Y states report one-step fit quality. They do not select map family, rank, α, stage, threshold or training epochs. No model/checkpoint exclusion follows from those numbers.

## Sealed predictions and outcomes

Before any composed forward, write predicted primary/full-token states and patched final vectors/scores for **every test scene/model** under V², VY (both orders), V²Y (both orders), and V⁴. Also seal identity, additive, generic MLP, raw-geometry and nearest-neighbor predictions, plus wrong-action and matched-norm random-direction patch states. The random directions use a fixed seed. Do not inspect or print aggregate composed predictions before sealing, to avoid adapting interpretation. Hash all files and emit `bd1_fit_freeze.json` with `composed_outcomes_observed=false`.

Then acquire actual BASE/V/Y replay and V²/VY/V²Y/V⁴ states for the 192 test scenes/model; replay singles within 1e-5. Verify checkpoint state unchanged. Compare target post-block-1 CLS; normalized final candidate vector; and score `10 cosine(q,c)`, using the unchanged oracle query. Patch each predicted CLS into an untouched copy of the actual BASE post-block-1 token tensor and execute the frozen final LayerNorm/readout. Full-token alternative patches its full tensor. The patch score must agree with direct mathematical readout within 1e-5. Wrong-action patches use Y for V² and V for Y-containing targets; random controls displace BASE CLS by the predicted displacement norm in a fixed isotropic direction.

## Predefined metrics, gates and interpretation

Report per model and pooled scene-level RMSE for CLS, final-vector Euclidean distance, and score; normalize each against identity on the same target. Break out unseen geometry versus withheld relational-pair strata and V², VY, V²Y separately. Report single-step validation separately. Report commutator `||T_YT_V(h)-T_VT_Y(h)||` and its second-order analogue relative to the actual composition displacement; report V⁴ state and score closure. Use model-level paired bootstrap (10,000 resamples of eight checkpoints) for descriptive uncertainty; the model is the replication unit. No post-hoc gating by a subset of scenes/models.

**Kill gate for the specified primary map:** if the primary map fails *any* of the following on pooled test scores, record B-D1 candidate A as failed and do not increase rank, add regimes or replace the stage: (i) V² and V²Y RMSE each ≤0.85×identity; (ii) V²Y RMSE ≤0.90×additive and ≤1.00×capacity-matched MLP; (iii) primary CLS RMSE on V²Y ≤0.85×identity; (iv) both VY and V²Y order-prediction commutator RMS ≤0.25×the corresponding actual displacement RMS; (v) patched score RMSE achieves the score gate, and the actual target patch reproduces direct target score within 1e-5; (vi) the score advantage over identity holds in at least 6/8 individual checkpoints, including at least two conditions in each seed, and on both geometry-test and withheld-pair strata. The raw-geometry/semantic and nearest-neighbor baselines are explanatory nulls: if either has lower V²Y score RMSE, the map may be predictive but does **not** earn an operation-level designation. A successful full-token alternative is reported as a distinct, higher-capacity hypothesis, never a primary rescue.

**Cross-seed transfer:** within each condition, align seed-1701 BASE CLS states to seed-1703 using only the 288 paired fit BASE scenes via orthogonal Procrustes with means. Conjugate the seed-1701 V/Y maps into seed-1703 coordinates, without using seed-1703 action states for this transfer; evaluate all test compositions. This is a hard secondary gate. Call the law reusable *across seeds* only if transferred V²Y patched-score RMSE ≤0.90×identity in at least 3/4 conditions and commutator gate holds. Independent same-family fits in both seeds are replication, not literal cross-seed transport.

Even if all numerical gates pass, call this only a **candidate-side nuisance transformation law in this synthetic model family**. The final-stage CLS patch alone does not identify the earlier computational mechanism, and raw-input symmetry may explain the law. A genuine transformer-native *relational* operation would need a later relation-changing action, mid-layer causal localization and separately frozen transport beyond this world. If gates fail, characterize the first failure by level (single step, repetition, composition, commutation, downstream, patch, scene/pair/seed) and stop candidate A without repair on these outcomes. P3.2-E remains unchanged in all cases.
