Replace only the candidate Transformer with a permutation-invariant DeepSets encoder: shared per-object `Linear(14,96)→GELU→Linear(96,96)→GELU`; sum across three objects; `Linear(96,96)→GELU→Linear(96,48)→LayerNorm(48)`. Keep the original Transformer oracle-message query branch and cosine four-choice scorer. Report trainable parameter counts. The architecture is a deliberately competent non-attention relational baseline, not parameter-exact matching. Shared pooling can represent inter-object functions through nonlinear postprocessing.

Train NO_CUE, CUE and P95 on the exact frozen B-D21/B-D23 data, seeds3801/3802, matched initialization and batch-index schedule within each seed, AdamW .0008, batch128, 3000 updates. Speaker/emit frozen as before. Save checkpoints at steps1000 and3000, report independent four-choice test accuracies and the same 600-scene relation×cue grid. Run the same held-identity fixed-ridge final-candidate relation and cue probes at step3000 if task accuracy reaches 0.95. No post-outcome architecture or optimizer tuning. If the control learns all tasks and reproduces candidate sensitivity/decodability shifts, the present acquisition effect is not specific to candidate self-attention. If it fails to learn, no architecture-specific conclusion follows. No protected/confirmation data or canonical mutation.
