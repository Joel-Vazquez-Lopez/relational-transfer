# B-D29 frozen discovery protocol: correspondence nulls

Status: **discovery only**. Chosen after B-D28 showed that eight ordered identity pairs suffice for substantial orthogonal query transfer. The hypothesis at risk is that pair-specific relational correspondence matters; a shared event axis may make arbitrary pair matching work.

Use B-D28's first eight fitting pairs and six held pairs, matched seeds 3801/3802, both NO_CUE↔CUE directions, and both full-query and event-difference fits. Fit a 48×48 orthogonal Procrustes map. No candidate vectors, geometry, scores, or held queries enter the fit.

For each condition evaluate: correct fit; 32 deterministic shuffled recipient pair correspondences that preserve event labels; 32 deterministic wrong-event correspondences that swap the recipient event labels independently in approximately half the fitting pairs. The randomization seed is 202629. All null draws are retained; none is selected. Evaluate held event-query cosine, score RMSE to recipient, concordant and conflict preference accuracy, and relation/cue contrasts. Report null distributions and correct-fit percentile. The recipient's own query remains the functional ceiling.

If pair shuffling matches the correct fit, the pair-specific gauge interpretation is rejected. If event swapping also matches, even event-semantic alignment is unsupported. All findings remain adaptive discovery evidence. P3.2-E unchanged; no protected/confirmation data.
