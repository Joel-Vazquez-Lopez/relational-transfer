# Protocol Auditor Experiment 02 — Own-benchmark shortcut falsification and counterbalance repair

**15 October 2026 | Executed local stdlib generator audit | No Transformer inference or patch results**

## Negative result: the original v1 design is not an acceptable standalone benchmark

A deliberately simple, label-free, **sorted-name + query-role** rule ignores clauses, verbs, voice, graph structure and even the query's event identity:

1. Extract the four names from the sentence and sort alphabetically.
2. If the question says actor, return the first name; if patient, return the second name.

On the original [`build_pairs.py`](build_pairs.py) stimulus generation, the *base* event is always (first alphabetic name, second alphabetic name), so this rule gets every base response right and two of four donor conditions right. Across all 512 base/donor pairs (**1,024 answer opportunities**) it gets **768/1,024 = 75%**. A strong score without event-specific information would invalidate unqualified aggregate-accuracy claims. This is a design falsification; **do not rewrite or delete v1**. In a causal patch analysis, use donor-specific paired transitions, not aggregate answer score.

## Revised v2: explicitly balanced fixed-name shortcut

New runnable files: [`build_pairs_v2.py`](build_pairs_v2.py), [`test_build_pairs_v2.py`](test_build_pairs_v2.py).

V2 retains the 512 paired tests (16 synthetic families × 2 grammatical voices × 2 clause orders × 2 query roles × 4 donor conditions), but rotates the four name assignments as a function of family and crossed condition. Each paired base/donor text still has the same word multiset; both sides use the **exact same question**. All 16 family IDs are disjoint, but the open-development and open-stress indicators are not sealed or independent confirmation.

Results of one locally executed deterministic Python audit:

| Audit | v1 | v2 | Interpretation |
| --- | ---: | ---: | --- |
| Sorted-name + question-role | **768/1024 (75%)** | **256/1024 (25%)** | Fixed name-order cue reduced to balanced four-way chance |
| Full direct local surface parser | Not a valid relational mechanism test | **1024/1024 (100%)** | Grammar remains exactly solvable by a question-time local text lookup |
| Gold-aware *in-sample ceiling* restricted to unordered word bag + exact query | Not assessed | **448/1024 (43.75%)** | Privileged fitted bound on **this exact multiset**; not a deployed predictor or generalization score |

The v2 25% figure holds for each of eight role × base/donor × four-condition strata when aggregated over 16 families. Dataset tests verify paired bag equality, unique IDs, gold flips, role balance, family splits and 100% direct parser success.

## What this does and does not establish

**Narrowly testable next claim:** Holding the verb and question fixed can challenge the hypothesis that Brain-O's patch affects output **solely** by switching the literal query verb. On competent models, measure donor-answer steering on same-query, different-binding worlds, with identity and distractor edits as negative controls.

**But:** the **100% direct surface lookup** demonstrates that even fully accurate answers do not require a persistent relational representation. Reaching high accuracy or even showing a query-token transplant effect here would not distinguish a pre-question relation cache from lexical syntax parsing, query-time reconstruction, a learned answer pointer, or generic hidden-state transport. Same-context token-bag equality is an input-control only, not a mechanism-identifiability proof.

Before a strong causal or novelty claim:
- Confirm actual Brain-O tokenizer and checkpoint compatibility. Do not train or patch without permission and preregistered location.
- Pin the transplant slice and donor pairing *before* viewing the patched output; include true same-verb and alternate-verb donors, random donors, identical-input self patches and unrelated-event controls.
- Present paired per-family effect sizes and uncertainty, preserving all clean-incorrect, invalid output and failed-patch records.
- Add a matched competence **query-time surface lookup** neural negative control that has access to the same text and can be subjected to exactly the same intervention; test several seeds and unseen families with changing entity/verb grammar.
- A further native mechanism claim needs a blinded diagnostic with known caching vs reconstruction controls sharing the same backbone, and human-reviewed authentic language.

**Scope:** This is a constructive *self-falsification* of the protocol auditor's own v1 stimulus benchmark, followed by a v2 repair of that one shortcut. It is not a discovery about LLMs, a complete solution to shortcut identification, or a measured effect of fine-tuning.
