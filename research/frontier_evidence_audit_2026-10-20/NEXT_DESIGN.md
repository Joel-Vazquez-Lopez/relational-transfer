# The two frontiers worth preserving

Design recommendations, 20 October 2026. No additional inference is launched by this document. Neither route is a newly identified mechanism or a claim that no one has tried its methodological ingredients.

## Preferred paper check: an independently designed causal analysis

Question: does answer-rule-dependent sample admission materially alter a causal conclusion outside our own binary templates?

First seek released per-example baseline scores, intervention scores and task/construction metadata from one published causal study. This is a data-availability audit, not permission to rebuild an unavailable training bank or download a large model. Do not choose the study because its effect changes under screening. Declare the target population and endpoint before calculating the screening sensitivity.

With existing outputs, retain the original native success-conditioned estimate and compute the original intervention endpoint on (a) all eligible cases, (b) common valid support, and (c) prespecified linguistic strata with fixed weights. If an alternative readout is justified, estimate it on a genuinely separate calibration partition and keep it fixed. Report all lost as well as rescued cases. Do not interpret a calibrated answer as the native model's behavior.

Support: a material, robust change in an explicitly stated conclusion, explained by measured admission shifts, with original raw effects retained. Challenge: the conclusion remains stable on common support/strata, or the difference is entirely a ratio-denominator artifact. Either is worth reporting. Adequacy of the published study must be judged against its own conditional question; a legitimate success-conditioned claim is not automatically an error.

Resources: CPU-only analysis if sufficiently granular artifacts are released. Stop if only aggregate plots are available. Do not silently substitute another authored prompt panel and call it external replication. Broader novelty and publication value remain to be assessed.

## Mechanistic frontier: reusable source information versus query-specific preparation

Operational question: can one fixed intervention on a source-only state change a *vector of downstream responses* coherently across future questions and answer encodings? This is more diagnostic than a single answer or a cosine, but a successful result would establish the tested functional reuse, not a uniquely semantic algorithm.

Use a source with independently variable directed event relations. Fork each identical source prefix into multiple future questions and counterbalanced answer mappings. Construct same-answer/different-source-relation and same-source-relation/different-answer pairs. Role-preserving reordering and syntax changes remain distinct controls, not interchangeable labels. Avoid reciprocal verbs and document AI-only annotation uncertainty. Source-only tensors must be computed at identical execution shapes; prove invariance to future query choice.

Three restricted accounts:

1. **Reusable relation-sensitive source variable:** one fixed donor intervention, selected only on development data, selectively changes the correct downstream response table across queries and output mappings. Changes should remain tied to source relations under name/order controls.
2. **Query-specific answer preparation:** transfer works only when donor and recipient requested answer agree, or requires a different map for each query/code. A pre-query intervention does not support the coherent response-table prediction even where a post-query intervention does.
3. **Nonspecific routing or attention modulation:** source availability/rescue changes contrast size, but opposite-relation donors do not selectively transfer the expected answer table; unrelated or role-preserving controls produce comparable changes. Our period-donation results are compatible with this account at the tested port, but do not establish it uniquely.

Before new inference, supply actual candidate sites and a prediction matrix where these restricted accounts disagree. The old period port has failed the claimed selective transport signature; do not choose a new port after observing held-out outcomes. Prove hooks, shams, source invariance, donor compatibility and full-answer scoring with known-program and numeric controls. No site currently passes this prerequisite for the proposed stronger claim.

A readout-only description of the proposed causal variable is inadequate. A source-side compound-key parser may implement the same response-table function as the proposed relation variable. If the accounts remain equivalent under every intervention we can make, narrow the claim to functional reuse and stop the algorithm-identification claim. Larger samples do not resolve logical equivalence.

Resources: existing local checkpoints and bounded disk-backed workers would suffice for a small pilot once the design separates the specified accounts. Attention/MLP instrumentation is useful only where it tests the declared dependency; recording more tensors alone is not a hypothesis test. No new call budget, execution or substantial inference is authorized by this recommendation itself.
