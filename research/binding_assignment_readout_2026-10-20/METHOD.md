# Exploratory complete-assignment readout

This is a post hoc saved-output analysis of exposed development data. Qwen's native outcomes were known; the idea was specified after seeing the first53 Llama outcomes(49 correct) while its frozen screen continued. It is not a held-out replication or a new native answer rule, and does not change native competence/causal admission. No additional model inference occurs.

For each source, collect the three question-conditioned leading-space full-name-prefix log probabilities into a3x3 matrix S(question role,person identity). Score each of the six one-to-one assignments π by sum_q S[q,π(q)]. Declare a unique output only if the best exceeds every other by1e-8; ties are ambiguous errors, not broken using gold. The best permutation is a fixed external decoder with no training or fitted threshold. It combines three model calls and the supplied one-to-one task constraint; it is not native behavior or evidence of a model-internal assignment solver.

Every permutation score is changed by the same constant under arbitrary row and column offsets S'[q,e]=S[q,e]+a[q]+b[e]. Thus all assignment margins are invariant to question offsets and shared name preferences within that source. This is elementary structured-prediction algebra, not a claimed novel method. It does not cancel arbitrary question-by-name interactions. Leading-space prefix scores omit EOS and alternate tokenizations, so they are not calibrated answer posteriors.

Four independent interaction coordinates can be written C[i,j]=S[i,j]-S[i,2]-S[2,j]+S[2,2],i,j<2. These cancel additive row/column effects. A common sent-person preference alone cannot distinguish full assignments. A single sent-person query row leaves at least two best assignments tied; both unknown roles must be distinguished by additional question-conditioned evidence for a unique correct full assignment.

Report all36 sources,including every native failure and structured-decoder failure,all six scores,gold margins and four contrasts. Arbitrary-offset metamorphic checks,constant-preference nulls and row-permutation relabelings validate algebra,not linguistic generalization. No p-value is calculated from36 dependent template cases. Syntax-aware copying,lookup tables and distributed output preparation remain viable. Availability through an external decoder does not establish causal use.
