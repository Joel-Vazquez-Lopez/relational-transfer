# Graded relational routing: a separately authorized continuation

This new investigation follows Joel's explicit correction that the previous stopped pilot did not complete his broader research request. Old protocols/results remain immutable. No paid APIs, training, cloud resources or model downloads. Existing local Qwen7B/Llama3B, one new run each, AI-only deterministic annotations. No new model or prompt search. This is a changed scientific endpoint, not a retroactive rescue of the closed pilot.

## Scientific target and three independent outcomes

Measure how graded output sensitivity to actor/object relationships depends on sentence-information routes. Native answer accuracy, independently calibrated classification, and causal changes in the graded response are distinct outcomes. Imperfect raw labels do not prohibit measuring a well-defined factorial response; they do prohibit claiming native correct answering. No case is dropped for answering incorrectly. Technical failures still stop invalid measurement.

Use the exact prior system/background/question templates. Six new name/verb families per model: g01/g02 development, g03..g06 evaluation. Each crosses Agent identity R, active/passive voice V, and query orientation Q; 8 prompts/family, 48/model. No old unexecuted evaluation family is reused. Identity and word order are not independent of voice/R; a marker-aware syntax/position copier remains a rival.

### Readout validation

Before new outputs, fit exactly one scalar threshold per model from the eight **already exposed** prior d1 baseline scores: midpoint between the highest false and lowest true Yes-minus-No alias score. Record the source hash and all fitting scores. Apply unchanged to every fresh normal prompt; retain original full-vocabulary argmax and class margins. No per-voice/lexicon/intervention refit. Calibrated accuracy is a fresh test of this simple rule; it is not native generation accuracy or evidence of a new calibration method.

### Primary continuous response

Let s(R,Q)=logsumexp(Yes aliases)−logsumexp(No aliases). Within a family/voice/condition define D=(s00−s01−s10+s11)/4. All four responses enter. This standard factorial contrast cancels a constant answer offset and additive R-only/Q-only terms exactly. It does not cancel arbitrary context-dependent biases or identify an abstract semantic variable. Positive D in both voices, with all four fixed-R/fixed-Q ordinal contrasts positive, is the declared criterion for role-consistent graded sensitivity. Require native D≥.5nat before interpreting normalized retention ratios. Below that floor, report the raw response and an undefined ratio; retain the failed unit. The .5 floor keeps the contrast above the .05nat logit technical tolerance; it is a declared pilot criterion, not a known linguistic constant.

## Causal interventions and complete collection

Reuse the prior exact masks and native block wrapper, with batch1/fixed128 and original assistant-end readout. Zero-based cut k affects blocks k..27. At each fixed k=0,7,14,21 collect closed, frozen, live, irrelevant. Collect neighbor at fixed14. Closed28 shams for role0/query0 in both voices, every family. All normal and intervention cells are collected for every family, including wrong answers. There is no all-correct-answer gate, no competent-subgroup substitution and no outcome-based early stopping for small/null D. We stop only on technical invalidity, exhausted budget, exception, or storage below1GiB. This permits heterogeneous and negative processing results without relabeling them as successes.

Closed removes later question access to all sentence information and prevents period refresh. Frozen removes period/upstream and question/upstream reads but permits question/period reads. Live permits period refresh while removing direct question/upstream reads. Neighbor preserves the preceding lexical token instead. Irrelevant translates the closed deletion pattern onto neutral keys with exact edge count/query indices. All later formatting/question tokens are included to close bypasses. Frozen means source-isolated, not numerically fixed. Existing pre-cut question states can contain information; carrier rescue is incremental usefulness alongside that state, not period-only sufficiency.

## Predictions fixed before outcomes

1. **Measurement null:** cut0 closed/frozen have no path from R-varying sentence words to period/suffix. Opposite-R surviving suffix states/logits must be identical; D=0. This is a graph/control prediction, not semantic competence.
2. **Fresh graded sensitivity:** D≥.5 and all conditional ordinal contrasts positive in both voices of all four evaluation families. Every failing unit remains a failure. Report raw and calibrated accuracy separately.
3. **Carrier alternatives:** cached carriage predicts frozen retention exceeding closed; continued refresh predicts live exceeding frozen; prior transfer into question states can preserve closed; dependence on direct original words can leave all carrier routes weak. These predictions are operational and not unique semantic algorithms.
4. **Fixed prospective route test:** on the two development families, select a cached signature first if possible, otherwise refresh. For each k7/14/21 require all4 family×voice cells to have valid native sensitivity; irrelevant retention within.25 of1; target retention≥.5; rival retention≤.75; target−rival≥.25. For cached target=frozen/rival=closed; refresh target=live/rival=frozen. Choose largest minimum cell effect, shallower tie. Save selection and all dev hashes **before any evaluation output**. No selected signature means no positive prospective route candidate; it does not cancel the fixed evaluation collection or permit selecting a favorable held site.
5. **Question-workspace alternative:** if neither carrier signature qualifies, test adjacent cut intervals(0,7),(7,14),(14,21), in that fixed order. Select the earliest interval in which all4 development family×voice cells have closed retention≤.25 at the lower cut and≥.75 at the upper cut, native D≥.5/all ordinal pairs positive, and neutral retention within.25 of1 at both cuts. This predicts that the graded response becomes maintainable in the question-side state without further sentence reads. It does not imply a unique variable, period mediation, completed linguistic computation, or absence of continued source use in the unmodified model.
6. **Evaluation:** the selected signature passes only if all8 evaluation family×voice cells satisfy the identical criteria at the unchanged cut (or both unchanged interval endpoints) and all technical controls pass. Report both voice outcomes per family; primary family success requires both. If no dev candidate, the prospective positive mechanism claim is unsupported and all evaluation profiles remain descriptive.

Each model selects independently. Two instances, one per family, cannot establish an architecture-family law. Different selected cuts may be reported, but no post hoc time warp, new sites or selective layer windows. No method-superiority/unique-semantics claim, even if all tests pass. A strong syntax-aware copier remains compatible with these pathway effects.

## Numerical controls and measurements

For each model compare native unwrapped, native wrapped, dense baseline and exact repeat on the first dev row; max logit discrepancy≤.05; repeat selected traces≤1e-6. Compare same-sentence period states across Q at fixed shape≤1e-6. Before-cut selected states and unaltered-prefix hashes must agree; live period must remain native; all shams must match native. All opposite-R cut0 closed/frozen full-suffix hashes must agree exactly and logits≤.05. Declared raw neutral drift is not a technical failure; it blocks clean signature interpretation by the frozen .25 criterion. Report it for every unit.

Save full-vocabulary original-end logits and measured residual traces (embedding and all28 block outputs, period and assistant end) for every call in compressed NPZ. Lossless float16 storage is permitted only after exact float32 round-trip equality; otherwise retain float32. This is storage encoding, not additional model quantization. Full-prefix and disconnected-suffix arrays used only for numerical controls are retained as exact hashes, not as separate full arrays. No attention/MLP contribution or complete token graph is claimed. Native operations/masks are unchanged from the prior engine; only embedding capture is added.

## Interpretation and novelty

NO-GO if the measurement is invalid or no operational signature prospectively generalizes. NARROW if a signature survives on fresh families: evidence about a tested dependency of a graded linguistic response. GO for a novel linguistic mechanism is not available from this design alone. Standard factorial contrasts, calibration and attention knockout are existing tools. Relevant precedents include Zhao2021, Geva2023, Dai2024 and Mixing Mechanisms; a successful result must be compared with their actual methods and later routing studies before a publication claim. The possible contribution is a reproducible empirical dependency/generalization pattern, not a new cosine or the generic readability/use distinction.
