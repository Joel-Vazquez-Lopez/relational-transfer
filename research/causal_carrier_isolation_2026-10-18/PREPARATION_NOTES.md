# Preparation before model outcomes

The first static preparation completed tokenization, model-file checksums, known-schedule calibration, mask/path certificates and persistence/scorer tests, then stopped at an initially conservative10GiB free-space assertion. Available storage was about5.6GiB. No model was loaded; no model forward occurred; no lock or protocol commit had yet been written.

Before freezing, replace that arbitrary quota with a tensor-size budget computed from each actual local model's vocabulary/width, all683 worst-case calls, and every extra disconnected-condition suffix capture. Require the full uncompressed array forecast plus20% overhead and2GiB reserve. This changes no scientific input, threshold or prediction; compression supplies additional savings. STORAGE_BUDGET.json preserves the exact estimate/free-space snapshot. Do not delete anyone's old experiments to make space.

The duplicate-persistence check was moved ahead of file writes before running the tests, so a duplicate cannot overwrite an earlier payload. No target outcomes informed that implementation correction.

All inputs are AI-authored simple transitive action sentences. Active/passive mappings and two opposite polar questions are programmatically checked. There is no reported human review, natural-corpus sample, independent annotator model or ambiguous intentionality theory. The labels concern whether the stated interaction has the named actor/object ordering. With no negation, embedding or extra event, the intended truth conditions are unambiguous within these fixtures. This does not guarantee all English wording is equally easy for the models.
