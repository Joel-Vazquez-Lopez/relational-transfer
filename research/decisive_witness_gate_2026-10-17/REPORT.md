## Proposed factorial and literal predictions

Let `E1` and `E2` be two distinct, originally annotated events with disjoint Agent and Patient fillers. The donor passage puts `E1` first, labels it `A`, and asks for EVENT A. The recipient independently varies complete event order (`E1` first or `E2` first), marker assignment (`A→E1` or `A→E2`), and question role (Agent or Patient). Apply the *previously identified* Qwen 7B layer-16 question-label patch; keep the same answer contract and otherwise appropriate shams. The full eight-cell pre-inference prediction matrix is [PREDICTIONS.json](PREDICTIONS.json), generated by [witness_certificate.py](witness_certificate.py).

| Explanation | Predicted participant source under the donor patch |
|---|---|
| Semantic event identity `EI` | Recipient `E1`, whichever position or arbitrary marker it has |
| Ordinal index `OI` | Recipient's first event |
| Strong syntax/content compound-key copier `CK` | Recipient record matching donor `E1`'s syntax/content key, then the queried role: recipient `E1` |

`EI` and `OI` disagree in 4/8 factorial cells, all with `E2` first. **`EI` and `CK` disagree in 0/8.** The strong copier is a concrete competent rival: it parses each event's predicate, participants and contextual descriptors into a local record, uses the donor label state as a content-address key, matches the recipient record after a permissible reorder/label swap, then copies the requested role filler. It gets all four untreated event×role questions right. A shared, query-aware content key can be encoded at the same residual-stream site as a purported semantic event ID, so swapping that vector can yield the same complete answers for both roles.

Identity, adjacent-token, same-position sham and unrelated-donor controls would test whether this *site* matters or whether donor names are blindly copied. Cross-document donors could rule out literal donor-name transfer and, when no content match exists, favor an order/index account. **None distinguishes `EI` from the competent `CK` on the proposed within-document counterbalanced cases.** Both can pass every listed control. Without an independent, justified restriction on what the copier may encode or an intervention that isolates a distinct native route, an `E1` answer does not identify an event-selector algorithm. Calling the same compound key a “semantic event address” does not create a different prediction.

This certificate does not prove that *no conceivable future mechanistic study* can distinguish restricted implementations. It proves that this single proposed patch and answer-source endpoint cannot deliver the requested `GO` claim against the explicitly required strong rival. Adding sample size, perfect four-answer baseline competence, additional marker swaps or another relation does not fix a zero-cell prediction disagreement.

## Decision and prior work

**NO-GO:** The competing event-identity and strong syntax/content copier explanations remain indistinguishable in the proposed observable space. The surviving empirical statement from prior work is narrower: the Qwen 7B question-label intervention can steer which local answer source is used on some natural passages, with an order/index cue a plausible explanation. It does not yet establish a distinct event-selection mechanism or two-role factorization.

[Dai, Heinzerling and Inui (EMNLP 2024)](https://aclanthology.org/2024.emnlp-main.967/) already report a causally editable binding-ID subspace that redirects entity–attribute recall. The exact natural-event setup here is different, but transferable binding/index steering alone is too close to claim novelty. The current no-run certificate makes no novel empirical claim.
