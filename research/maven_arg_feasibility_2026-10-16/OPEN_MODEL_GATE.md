# Open-weight competence gate — 16 October 2026

After the hosted Gemma and small-Qwen results were visible, I selected the existing local 4-bit MLX conversion of `Qwen2.5-7B-Instruct` to check whether an accessible model can solve the same natural event × role panel. This is **adaptive model selection**, not a new held-out model comparison.

The [protocol](PANEL_V2_QWEN7B_PROTOCOL.json) was frozen before inference (SHA-256 `34f3c75ac7b62c3b79b37c77ec173f173e45d3afe573c13d4f750048bc0d0471`). The model is the prior pinned `mlx-community/Qwen2.5-7B-Instruct-4bit` conversion at revision `c26a38f6a37d0a51b4e9a1eb3026530fa35d9fed`, with 4-bit group-size-64 quantization. It ran locally with greedy decoding, 24 new tokens, and the same semantic questions as the 17-document panel. The older [model metadata](../stronger_model_development_2026-10-15/qwen7b_META.json) records file hashes and runtime provenance.

On the 68 questions, Qwen 7B returned **49 exact local mentions** and **58/68 exact-or-unique-alias matches** under the previously frozen panel score. It answered all four questions on **10/17 documents**. There were **six same-event wrong-role answers**, **four unmatched outputs**, and **six of 34 events** with identical Agent and Patient answers. By event type: Conquering 30/32, Military_operation 11/12, Bringing 3/4, Control 14/20. Two unmatched Conquering outputs merely omitted leading articles (`Mongol Empire`, `Qara Khitai`); two others output a trigger word (`defeating`, `command`). The six wrong-role answers concentrate on commander/commanded-force relations, with one ship/commander swap.

This clears a **narrow competence gate** for causal development on straightforward defeat events: an open-weight model is available and gets 30/32 alias-rule answers in that stratum. It does not clear a global event × role mechanism gate. The model is weaker on Control, and the current panel contains almost no wrong-event selections for this model. A patch that changes an answer on easy questions would not by itself distinguish a shared event selector from lexical copying or query routing. Any activation study should first freeze rival predictions and find stable, competence-matched source/target pairs that genuinely separate them.
