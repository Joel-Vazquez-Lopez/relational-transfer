# Brain-O — Query factorization study (Experiments 010–015)
Date: 15 October 2026 · Status: **EXPLORATORY, SYNTHETIC, NOT A PRETRAINED-LLM MECHANISM**

## Core observation
Small trained causal Transformers on two structured events answer *which role?* but usually not *which verb?*. The question token occupying the last input position strongly changes which factor governs answers, while correct joint event–role addressing remains unsolved.

### Frozen final-state probes (Experiment 010)
Using 1,200 generated training event graphs and 300 distinct evaluation graphs (four questions per graph), the trained seed-1016 Transformer yielded **59.5% linear**, **60.0% nonlinear** final-state readout accuracy. The native classifier scored **60.0% on this exact evaluation split**. A nonlinear readout on a randomly initialized backbone scored 44.5%. No evidence of an easily recovered high-accuracy binding state. Probe-fitting used exploratory evaluations; final-epoch results are given rather than test-selected maxima.

### Input sensitivity (Experiment 011)
On 700 paired query interventions per seed:
- Mean ratio `L2(hidden response to verb swap) / L2(hidden response to role swap)` was approximately **0.9%, 1.4%, 1.7%** across baseline seeds 1015, 1016, 1017.
- Baseline models barely altered output when asked about a different verb. These are sensitivity measurements, not mutual information or proof of binding absence.

### Reversing query-token order (Experiment 012)
The model originally reads `[Q,VERB,ROLE]`; the intervention trains `[Q,ROLE,VERB]`. On 600 disjoint event cases per seed after 500 training steps:
- Seed 1015: **24.3%** verb-switch response, **1.7%** role-switch response, **25.3%** accuracy.
- Seed 1016: **29.8%** verb-switch response, **2.2%** role-switch response, **25.7%** accuracy.
- The query-factor dominance changes, but *the task is not solved*. The original seed-1016 checkpoint was also 500 steps and allows a matched-step comparison. The original seed-1015 checkpoint was **continued to 1,600 steps** and should NOT be described as matched to 500-step reordered seed-1015.

### Verb injection into final token without retraining (Experiment 013)
Adding the correct queried-verb embedding to the final role-state changes some outputs, but correct versus wrong-verb injection yields comparable accuracy; no reliable repair. This is an out-of-distribution state edit.

### Parameter-free joint embedding at training time (Experiment 014)
The network was trained with terminal input `E(role)+E(verb)+position` rather than `E(role)+position`, with no new parameters. Seed-1015 500-step results: **51.7%** disjoint, **74.8%** same-agent, **75.7%** same-patient, **52.0%/48.7%** cross-role; **12.7%** verb-switch response on disjoint examples. Still near the role-marginal plateau. Single seed; baseline seed-1015 training length is not matched.

### Native model evaluation (Experiment 015)
On the exact frozen-probe test set (1,200 QA cases): seed-1015 **59.75%**, seed-1016 **60.0%**, seed-1017 **59.92%**. Accuracy on disjoint/cross-role cases near 50%, shared-role near 75%.

## Working hypothesis
The model exhibits an effective **query-factorization defect**: it learns an approximate shortcut `f(G,v,r)≈g(G,r)` when the role is terminal, and favors `f(G,v,r)≈h(G,v)` when the verb is terminal. This is a behavioral factorization, **not a discovered neural representation**. Last-token residual access supplies an architectural explanation to test, but does not yet explain why event binding fails.

## Must-pass gates
1. Achieve a learned >=95%-accurate positive control on the **same two-event grammar** across seeds.
2. Compare neutral readout tokens, controlled terminal pooling, query-position randomization, and query composition while matching training compute/parameters.
3. Causally test source-event binding separately from output addressing; reject probes that infer arbitrary bindings from random networks.
4. Confirm on unseen composition patterns and independently verified natural language; examine prior work on prompt order, positional shortcuts, entity binding, and compositional retrieval.

**No novelty, transferable repair, causal mechanism, or pretrained-LLM claim is established.**
