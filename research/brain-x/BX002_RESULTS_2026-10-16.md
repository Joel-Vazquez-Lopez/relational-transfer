# BX-002 — Paired constraints: causal sensitivity without useful accuracy gains

**Date:** 2026-10-16. **Status:** completed CPU synthetic development study, negative finding. NOT authentic language, pretrained LLM mechanism, novelty confirmation, or independent structural replication. Supersedes the *unpaired* aspect of BX-001; original negative BX-001 remains intact.

## Experiment

Five uniform latent bits arranged on a fixed ring; each node observation flips with p=0.35, each valid observed parity edge flips with q=0.08. For every one of 4,000 heldout worlds (fixed test generator seed 802002), the latent world, noisy node observations, question and gold queried-bit answer are IDENTICAL between the valid-edge and random-edge pair. Only the five edge observation values change. Random-edge observations are independent fair bits.

Three-layer 48-wide, 4-head TransformerEncoder with 96-wide feedforward layers, 1,200 steps, minibatch 128, AdamW lr=.002, weight decay=.001, dropout 0; seeds 17 and 29. 22,000 independent train worlds per seed. Edge-mode models train on a mixture: 80% valid-edge worlds + 20% random-edge worlds, with no explicit reliability flag. Node-only controls have identical training worlds, labels, query, architecture, initialization seed, optimizer, steps and token layout but edge VALUES are zero-masked. Same underlying 4,000 test worlds used for both training seeds, so not independent structural replication.

**Exact source:** research/brain-x/bx002_paired_syndromes.py (Git blob SHA 7bd6bfe2b3af80b88ec91e8b212d124c3fd263fe), identical to the tested local source by git hash-object. Invariant tests: test_bx002_paired_syndromes.py. Five local tests passed; initial test fixture had an incorrect manually expected contingency tuple, which was corrected without altering the experiment. Python 3; torch 2.10.0+cpu; numpy 2.3.5.

## Actual results, fixed 4,000 worlds

| Model / rule | Informative edges | Random edges | Paired informative-only correct | Random-only correct |
|---|---:|---:|---:|---:|
| Local queried observation | 65.30% | n/a | n/a | n/a |
| Simple majority of local and two neighbor/parity votes | 69.875% | n/a | n/a | n/a |
| Exact Bayesian marginal, known p and q | 73.125% | n/a | n/a | n/a |
| Transformer edge, seed 17 | 65.15% | 62.95% | 268 | 180 |
| Transformer edge, seed 29 | 65.35% | 63.625% | 128 | 59 |
| Transformer node-only, seed 17 | 65.30% | 65.30% | 0 | 0 |
| Transformer node-only, seed 29 | 65.30% | 65.30% | 0 | 0 |

Against the LOCAL observation baseline, trained edge model rescue/harm counts: seed 17 **161/167** (−0.15 percentage points), seed 29 **57/55** (+0.05 points). Simple unprivileged neighbor/parity voting rescues 541 versus 358 harms (+4.575 pp). Exact Bayes rescues 656 versus 343 harms (+7.825 pp); Bayes knows generative noise parameters and is a reference, not a fair learned baseline.

**Finding:** A fixed model changes accuracy by 2.2 points (seed 17) or 1.725 points (seed 29) when ONLY edge information is randomized, yet the model's performance on valid edges does not appreciably exceed local-only. Sensitivity to edge intervention does NOT establish beneficial integration of the edge constraints. The simple voting algorithm recovers significant available signal which this trained Transformer largely misses. This is a negative regime-specific result, NOT proof that all Transformers lack constraint reasoning. Valid/random counterfactuals are different observation distributions, but both types occur in training; this does not identify a semantic circuit.

## Novelty and next gate

Error-correction Transformers and belief-propagation-assisted architectures are prior art: Choukroun & Wolf ICLR 2024, A Foundation Model for Error Correction Codes; Zheng et al. 2025, White-box Error Correction Code Transformer; CrossMPT ICLR 2025. A generic parity objective, exact Bayes control, trained syndrome decoder, or graph factor inference is not new. The narrower scientific question is when native causal INFORMATION SENSITIVITY fails to produce positive INFORMATION UTILITY in actual role answering and how to separate this from format, lexical copying, and inference-budget artifacts. Existing causal assessment methods also address this; novelty is not established.

Given the lead's real-language and pretrained-LLM requirement (issue #23), do not schedule more expensive ring sweeps now. Next direct test: doubly adjudicated authentic same-event informative-vs-irrelevant context pairs, matched direct versus joint extraction interfaces, lexical/syntax and complement-only baselines; two frozen pretrained families only after dataset and competence/format gates.
