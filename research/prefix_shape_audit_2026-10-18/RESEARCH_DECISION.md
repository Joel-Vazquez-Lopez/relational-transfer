# What to build a paper around, given the evidence

18 October 2026. This is an evidence-based research decision, not a claim that the following paper is already demonstrated or novel. No new semantic experiment was launched after the bounded numerical audit.

## The result acquired in this investigation

The earlier prefix-invariance failure has a concrete, reproduced numerical explanation on the exposed Qwen fixtures. A fixed suffix-length sweep, future-content controls, repeats, isolated projections and equal-shape real-prompt controls separate execution shape from future-token content. A Llama model on the same backend shows the same discontinuity. This is an architecture check under a shared runtime, not independent backend replication.

In the previously saved component map, an apparently role-related contrast at the first person's token is exactly the shape-only numerical contrast across every block and all four components, in both exposed Qwen families. At the sentence-final outgoing state the numerical contrast is much smaller than the linguistic contrast. This is a precise local result with positive controls and an explicit limit, not a generic declaration that interpretability is unreliable.

## My research recommendation

Keep computational-development comparison as the subject. Change the question from “can we find similar-looking paths?” to:

**Which conclusions about shared computation survive controls that independently vary the task, the answer readout and the execution schedule?**

A useful provisional title is **Calibrating Layerwise Comparisons with Causal-Prefix Nulls**. The contribution would be a validated measurement/evaluation protocol and a demonstrated change in scientific conclusions, rather than another renamed cosine or an alleged universal role circuit.

The current evidence supports a technical report or a component of the course investigation. A stronger paper needs more evidence. This audit alone is too narrow to promise main-conference publication.

## A concrete comparison, rather than another unfalsifiable mechanism search

| Controlled change | What is known | What a descriptor must do |
|---|---|---|
| Change only future suffix content at fixed shape | Captured causal prefix has identical mathematical input | Remain within its empirically measured numerical floor |
| Change only execution shape | Same mathematical prefix computation | Expose numerical sensitivity; do not label it semantic change |
| Change linguistic relation after a measured token | No causal access to that later change | Do not infer early role encoding from a nonzero contrast there |
| Change relation before the measured token | Legitimate input difference | Detect it where supported; direction alone does not identify mechanism |
| Change requested person/output mapping | Answer readout changes | Separate readout similarity from input-relation similarity |
| Change implementation on a system with known functional ground truth | Ground truth specified independently | Test sensitivity to functional change and specificity to nuisance changes |

The next confirmatory dataset must be frozen independently of these exposed cases. Compare standard RSA/CKA, existing trajectory descriptors and a depth-only baseline before introducing a new measure. Evaluate whether rankings or functional predictions change under fixed-shape controls. Keep family and backend units separate; hundreds of layer coordinates are not hundreds of independent replications. Require an effect on an actual scientific conclusion, not merely a tiny nonzero numerical discrepancy.

That study is not run here. It should also include a genuinely independent runtime or a reference execution using the same weights, after a compatibility check. Adding another model to the same backend is insufficient to establish backend generality.

## The semantic route still available

If the goal remains an empirical linguistic paper, the strongest existing behavioral lead is the preposed named-observer boundary in the [prior replication](../paper_pivot_2026-10-17/NAMED_OBSERVER_REPLICATION_REPORT.md): Qwen's second-event errors occurred on competent preposed named-observer variants, while matched unnamed and postposed variants were clean in that panel. The broad law failed its frozen criterion, so the narrowed claim is exploratory. It merits a prospective natural-language test only with validated annotations, competing position/entity baselines and independent replication. It does not justify reopening the unique-event-selector claim.

## Decision

**GO for the local numerical diagnosis and a fixed-shape measurement control. NARROW for the present empirical contribution. No demonstrated novel semantic mechanism, no universal cross-model path, and no guaranteed paper.** The practical gain is that one real technical blocker has been explained and one misleading map channel has been precisely identified. Future studies can now distinguish measurement validity, model competence and mechanism identification rather than treating them as one failed hypothesis.
