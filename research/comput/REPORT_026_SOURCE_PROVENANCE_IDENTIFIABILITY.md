## Exact identifiability claim

For any passage with exactly two distinct events (E1 first, E2 second), when the query targets E2, there is only **one** alternative event: E1. A policy choosing the *other event* and a policy falling back to the *first event* thus make **identical source predictions for all seven reported errors**. Neither requires a separately identifiable latent event-binding mechanism. This is a logical equivalence conditioned on the *reported observed subtype*, not proof that either algorithm exists in Qwen.

To differentiate **restricted** alternatives, construct three well-annotated events with six distinct Agent/Patient fillers; cross event order, queried event, requested role and irrelevant-name load. The independent executable toy certificate enumerates **72 cells** (3! orders × 3 targets × 2 roles × 2 loads), including 36 loaded cases. Predictor candidates: (a) exact query-conditioned reader, (b) overloaded first-record fallback, (c) overloaded query-aware same-verb/compound-key copier, (d) overloaded closest-previous-record fallback. All are correct on toy unloaded cases. Among loaded cases, first-record fallback disagrees with exact reader in **24/36**, content copier in **20/36**, and closest-record fallback in **24/36**. These **are predictions only, NOT LLM measurements or estimated rates**.

Example, target E3.Agent and source order [E2,E1,E3]: gold E3=Enzo; first-record fallback E2=Cleo; same-verb alternative E1=Ada; closest record E1=Ada. With order [E1,E2,E3], first and same-verb select E1/Ada while closest selects E2/Cleo. With only two events and target second, first vs other-event sources coincide in **all four symbolic loaded cells**. Full table and testable certificate in ZIP.

**Hard bound:** A competent unrestricted syntax+position+salience+compound-key copier can emulate semantic event-address behavior for all observable prompt labels. This table isolates ***restricted*** rivals, **not** a unique neural semantic algorithm. It does not reverse Codex's earlier causal-patch NO-GO or establish a publishable novelty claim.
