# Astra reboot audit bundle

This bundle contains the report, independent recount code and outputs, a metadata-only historical exposure ledger, and selected source records. It is not the full project archive and does not contain checkpoints or corpus text. audit_saved.py expects the original workspace experiment files and paths; its RECOUNT records their hashes. COMPASS_REPLAY is a deterministic certificate replay, not a neural replay. Prior history outside the independently recounted subsets is marked REPORTED.
